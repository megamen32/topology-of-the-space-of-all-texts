# Научная программа завершения математического ядра «Библиотеки Вавилона»

## 1. Назначение документа

Это **не план разработки**, не список файлов и не декомпозиция задач для программиста.

Документ определяет научную работу, которая должна предшествовать окончательной реализации:

- что именно является математическим объектом проекта;
- какие утверждения должны быть доказаны;
- какие свойства невозможно доказать и нужно проверять экспериментально;
- какие альтернативные гипотезы необходимо сравнить;
- при каких результатах исследование считается завершённым;
- когда допустимо переходить к полной инженерной декомпозиции.

Центральная цель — построить конкретную версию библиотеки:

\[
\operatorname{Babel}_1:
\{0,\ldots,256^{4096}-1\}
\longleftrightarrow
\Sigma^{4096},
\]

где \(|\Sigma|=256\), обладающую двумя разными классами свойств:

### Строго математические свойства

1. Каждый номер соответствует ровно одной странице.
2. Каждая страница имеет ровно один номер.
3. Покрыты все \(256^{4096}=2^{32768}\) страниц.
4. Преобразования `rank` и `unrank` являются точными взаимными обратными.
5. Результат воспроизводится независимо от компьютера и реализации.

### Статистические свойства

1. В начале нумерации страницы чаще похожи на человеческий текст.
2. При движении в глубину пространства качество в среднем ухудшается.
3. Соседние номера желательно дают разные страницы.
4. Дальний хвост преимущественно выглядит как шум.
5. Русский, английский и смешанный человеческий текст не вытесняют друг друга полностью.

Главный принцип исследования:

> **Биекция должна быть доказана. Человечность порядка должна быть измерена.**

Нельзя смешивать эти два требования в одну задачу.

## 2. Центральная математическая гипотеза

Недостающая конструкция должна состоять из двух независимых преобразований:

\[
\text{номер}
\longleftrightarrow
\text{латентная последовательность}
\longleftrightarrow
\text{текстовая страница}.
\]

Первое преобразование отвечает за точный порядок и подсчёт.

Второе отвечает за языковое качество.

### 2.1. Латентная страница

Определим:

\[
Z=\{0,\ldots,255\}^{4096}.
\]

Элемент

\[
z=(z_1,\ldots,z_{4096})
\]

не является текстом.

Каждый \(z_i\) означает номер одного из 256 доступных вариантов продолжения:

```text
0   → один из наиболее подходящих вариантов;
1   → следующий вариант;
...
255 → один из наиболее неподходящих вариантов.
```

### 2.2. Контекстная перестановка

Для любого уже восстановленного префикса \(p\) языковая модель должна вернуть полную перестановку алфавита:

\[
\pi_p:
\{0,\ldots,255\}\rightarrow\Sigma.
\]

Она обязана содержать все 256 символов:

- без пропусков;
- без повторов;
- в строго детерминированном порядке.

Тогда текст строится последовательно:

\[
x_i=\pi_{x_{<i}}(z_i).
\]

При обратном преобразовании:

\[
z_i=\pi^{-1}_{x_{<i}}(x_i).
\]

Это дискретное треугольное обратимое преобразование. Родственные идеи используются в дискретных нормализующих потоках и обратимых целочисленных моделях, где преобразование дискретных данных строится как точная биекция. citeturn642661view5turn642661view4

### 2.3. Главное математическое упрощение

Языковая модель **не назначает стоимость символу напрямую**.

Она только решает, какой символ будет находиться в каком латентном слоте.

Стоимость принадлежит номеру слота:

\[
c:\{0,\ldots,255\}\rightarrow\mathbb Z_{\ge 0}.
\]

Следовательно, при любом контексте имеется один и тот же набор возможностей:

```text
столько-то слотов стоимости 0;
столько-то слотов стоимости 1;
столько-то слотов стоимости 2;
...
```

Модель лишь переставляет реальные символы между этими слотами.

Отсюда следует центральная идея всего исследования:

> Число продолжений каждой стоимости не зависит от языкового контекста, потому что каждый контекст содержит один и тот же набор латентных слотов.

Поэтому при точном подсчёте больше не нужно хранить состояние языковой модели, кластер текста или весь префикс.

Контекст может быть сколь угодно сложным. Пока он только определяет перестановку 256 символов, точный подсчёт остаётся контекстно-независимым.

# STAGE 0. Формализация объекта библиотеки

## Научный вопрос

Что именно означает утверждение:

> «В библиотеке присутствует каждая возможная страница»?

До следующих стадий необходимо устранить неоднозначность между:

- байтами;
- символами выбранного алфавита;
- символами Unicode;
- текстами переменной длины;
- страницами после нормализации и дополнения пробелами.

## Рекомендуемое определение

Основной математический объект:

\[
\Sigma=\{0,\ldots,255\},
\qquad
L=4096.
\]

То есть страница является последовательностью из 4096 байтов.

Тогда:

\[
|\Sigma^L|=256^{4096}=2^{32768}.
\]

Это позволяет буквально утверждать:

> В библиотеке присутствует каждая последовательность из 4096 байтов.

Любой текст в UTF-8 представим в библиотеке, хотя часть страниц не является корректным UTF-8. Такие страницы должны отображаться экранированно или в специальном байтовом режиме.

Альтернативное определение — 256 заранее выбранных отображаемых знаков — также допустимо, но тогда утверждение должно звучать так:

> В библиотеке присутствует каждая страница над данным фиксированным алфавитом.

## Отдельная проблема коротких текстов

Текст переменной длины не должен отождествляться с дополненной страницей без явной спецификации.

Например, строки:

```text
"текст"
"текст "
"текст  "
```

не должны случайно получать один адрес из-за удаления хвостовых пробелов.

Необходимо определить инъективное вложение короткого текста в страницу. Например:

\[
E(y)=
\operatorname{length}(y)
\Vert y
\Vert 0\ldots0.
\]

Длина должна быть записана в заголовке страницы либо кодироваться другим однозначным способом.

## Обязательный научный результат Stage 0

Формальная спецификация:

\[
\mathcal U=(\Sigma,L,\operatorname{render},E).
\]

В ней фиксируются:

- алфавит;
- длина страницы;
- байтовый порядок;
- способ отображения невалидного текста;
- вложение короткой строки;
- различие между точным поиском страницы и поиском нормализованного текста.

## Критерий завершения

Любые два независимых исследователя должны одинаково ответить:

1. Входит ли заданная последовательность в пространство страниц?
2. Сколько всего страниц?
3. Какой точный массив из 4096 элементов ранжируется?
4. Является ли пользовательская нормализация частью биекции?

До этого момента дальнейшие доказательства считаются условными.

# STAGE 1. Теорема о контекстной перестановочной биекции

## Научный вопрос

Можно ли использовать произвольно сложную языковую модель для улучшения текстов, не включая её состояния в точный глобальный подсчёт?

## Определение

Пусть для каждого префикса

\[
p\in\Sigma^{<L}
\]

задана перестановка

\[
\pi_p\in S_{256}.
\]

Определим преобразование \(T_\Pi\):

\[
T_\Pi(z)=x,
\]

где

\[
x_i=\pi_{x_{<i}}(z_i).
\]

## Теорема 1. Контекстная биективность

Для любого семейства перестановок

\[
\Pi=\{\pi_p\}_{p\in\Sigma^{<L}}
\]

преобразование

\[
T_\Pi:
\{0,\ldots,255\}^{L}
\rightarrow
\Sigma^L
\]

является биекцией.

Его обратное преобразование вычисляется последовательно:

\[
T_\Pi^{-1}(x)_i=
\pi^{-1}_{x_{<i}}(x_i).
\]

## Логика доказательства

Доказательство проводится индукцией по позиции.

На позиции \(i\):

1. Префикс \(x_{<i}\) уже однозначно известен.
2. Следовательно, однозначно известна перестановка \(\pi_{x_{<i}}\).
3. Поскольку это перестановка, для каждого \(z_i\) существует ровно один \(x_i\).
4. Для каждого \(x_i\) существует ровно один обратный образ \(z_i\).

Таким образом, последовательность восстанавливается позиция за позицией без ветвления и неопределённости.

## Что эта теорема разрешает

Перестановка может зависеть от:

- всего префикса;
- скрытого состояния нейронной сети;
- языка;
- пунктуации;
- длины серии повторов;
- вероятности следующего символа;
- внешнего классификатора;
- любых эвристик.

Ни качество модели, ни корректность её предсказаний не влияют на биективность.

Плохая модель ухудшит начало библиотеки, но не создаст:

- дыр;
- дубликатов;
- неоднозначных адресов.

## Условия теоремы, которые нельзя ослаблять

Для каждого префикса модель обязана выдавать:

1. все 256 символов;
2. каждый ровно один раз;
3. детерминированный порядок;
4. детерминированное разрешение равных оценок.

Если модель выдаёт только `top-k`, используется случайная выборка или порядок зависит от плавающей арифметики платформы, спецификация неполна.

## Обязательный научный результат Stage 1

Полное доказательство теоремы и формальная спецификация функции:

\[
p\mapsto\pi_p.
\]

## Критерий завершения

Для уменьшенных пространств:

\[
q\in\{2,3,4,8\},
\qquad
L\le 8
\]

выполнен полный перебор и подтверждено:

\[
T_\Pi^{-1}(T_\Pi(z))=z
\]

для всех \(z\).

При этом тест является лишь проверкой реализации. Общая корректность должна следовать из доказательства.

# STAGE 2. Теория латентных энергетических оболочек

## Научный вопрос

Как точно перечислить все латентные страницы так, чтобы сначала шли последовательности из хороших слотов, а затем постепенно добавлялись менее удачные варианты?

## 2.1. Общая стоимость

Задаётся целочисленная функция:

\[
c:\{0,\ldots,255\}\rightarrow
\{0,\ldots,C\}.
\]

Стоимость латентной страницы:

\[
W(z)=\sum_{i=1}^{L}c(z_i).
\]

Определим оболочку энергии \(e\):

\[
S_e=\{z:W(z)=e\}.
\]

## 2.2. Генерирующая функция

Для одной позиции:

\[
G(t)=
\sum_{r=0}^{255}t^{c(r)}.
\]

Тогда число страниц энергии \(e\):

\[
A_e=
[t^e]G(t)^L.
\]

Здесь \([t^e]\) означает коэффициент при \(t^e\).

## Теорема 2. Точный размер оболочки

\[
|S_e|=A_e.
\]

Кроме того:

\[
\sum_e A_e
=
G(1)^L
=
256^L.
\]

Следовательно, объединение всех оболочек покрывает всё пространство латентных страниц без потерь.

Это прямое применение логики перечислительного кодирования: объект получает индекс через точный подсчёт допустимых продолжений. Такой подход восходит к enumerative source encoding Ковера; shell mapping использует близкую идею для фиксированного обратимого отображения последовательностей по весовым оболочкам. citeturn747293search0turn642661view1

## 2.3. Рекуррентная форма

Определим:

\[
N(m,e)=
\text{число последовательностей длины }m
\text{ с энергией }e.
\]

Начальные условия:

\[
N(0,0)=1,
\]

\[
N(0,e)=0
\quad\text{при }e\ne0.
\]

Рекурсия:

\[
N(m,e)=
\sum_{r=0}^{255}
N(m-1,e-c(r)).
\]

Если стоимости объединены в группы, где \(m_j\) слотов имеют стоимость \(w_j\), то:

\[
N(m,e)=
\sum_j m_jN(m-1,e-w_j).
\]

Языковая модель в этой формуле отсутствует.

## 2.4. Бинарная базовая конструкция

Для первого полного доказуемого варианта необходимо взять:

\[
c_K(r)=
\begin{cases}
0,&r<K,\\
1,&r\ge K.
\end{cases}
\]

Тогда энергия — число позиций, где выбран вариант вне первых \(K\).

Размер оболочки \(s\):

\[
A_s=
\binom{L}{s}
K^{L-s}
(256-K)^s.
\]

И:

\[
\sum_{s=0}^{L}
\binom{L}{s}
K^{L-s}
(256-K)^s
=
256^L.
\]

Эта версия должна стать **математическим эталоном**, даже если позже для качества будет выбрана более плавная стоимость.

## 2.5. Точная нумерация внутри оболочки

Для страницы \(z\) известна оставшаяся энергия \(e\).

При обработке позиции \(i\) для каждого меньшего варианта \(r<z_i\) прибавляется:

\[
N(L-i,e-c(r)).
\]

После выбора фактического \(z_i\):

\[
e\leftarrow e-c(z_i).
\]

Это задаёт точный лексикографический ранг внутри оболочки.

Обратный алгоритм последовательно выбирает единственный символ, в чей диапазон размеров продолжений попал заданный локальный номер.

## Обязательные результаты Stage 2

Должны быть доказаны:

1. формула размера оболочки;
2. рекуррентная формула;
3. корректность внутреннего `rank`;
4. корректность внутреннего `unrank`;
5. отсутствие пересечений оболочек;
6. полное покрытие \(256^L\).

## Критерий завершения

Для бинарной стоимости получено доказательство в закрытой форме.

Для общей многоуровневой стоимости подтверждено:

\[
\sum_e N(L,e)=256^L.
\]

На малых \(q,L\) полностью перебраны все последовательности и проверено, что локальные ранги каждой оболочки образуют диапазон:

\[
0,\ldots,A_e-1.
\]

# STAGE 3. Теорема о глобальном `rank/unrank`

## Научный вопрос

Как объединить контекстную языковую биекцию и точное перечисление оболочек в одну библиотеку?

## 3.1. Порядок оболочек

Пусть \(\rho\) — полный порядок всех возможных значений энергии.

Он необязательно обязан совпадать с обычным порядком \(0,1,2,\ldots\). Это важное место для будущего исследования качества.

Определим смещение оболочки:

\[
O_e=
\sum_{\rho(e')<\rho(e)}
A_{e'}.
\]

## 3.2. Перемешивание внутри оболочки

Для каждой оболочки может быть выбрана любая биекция:

\[
P_e:
\{0,\ldots,A_e-1\}
\rightarrow
\{0,\ldots,A_e-1\}.
\]

Она нужна для того, чтобы соседние номера не отличались только последними символами.

Перемешивание не должно переносить страницу между оболочками.

## 3.3. Глобальный ранг

Пусть:

\[
z=T_\Pi^{-1}(x),
\qquad
e=W(z).
\]

Тогда:

\[
\operatorname{Rank}(x)
=
O_e+
P_e^{-1}
\left(
\operatorname{Rank}_e(z)
\right).
\]

## 3.4. Глобальное восстановление

Для номера \(n\):

1. находится единственная оболочка \(e\), для которой

\[
O_e\le n<O_e+A_e;
\]

2. вычисляется локальный индекс

\[
u=n-O_e;
\]

3. применяется перестановка

\[
v=P_e(u);
\]

4. восстанавливается латентная страница

\[
z=\operatorname{Unrank}_e(v);
\]

5. строится текстовая страница

\[
x=T_\Pi(z).
\]

## Теорема 3. Глобальная биекция

Если:

- \(T_\Pi\) является биекцией;
- внутренний `rank/unrank` каждой оболочки является биекцией;
- \(\rho\) является полным порядком оболочек;
- каждое \(P_e\) является перестановкой;

то:

\[
\operatorname{Rank}:
\Sigma^L
\rightarrow
\{0,\ldots,256^L-1\}
\]

и

\[
\operatorname{Unrank}:
\{0,\ldots,256^L-1\}
\rightarrow
\Sigma^L
\]

являются взаимно обратными.

То есть:

\[
\operatorname{Rank}(\operatorname{Unrank}(n))=n,
\]

\[
\operatorname{Unrank}(\operatorname{Rank}(x))=x.
\]

## Обязательный результат Stage 3

Единая доказанная композиция:

\[
\boxed{
\operatorname{Babel}
=
T_\Pi
\circ
\operatorname{ShellUnrank}
\circ
P
}
\]

и её явное обратное преобразование.

## Критерий завершения

Ни один последующий выбор языковой модели, функции качества или порядка оболочек не требует изменения доказательства глобальной биекции.

Это главный математический рубеж исследования.

# STAGE 4. Связь с точной вероятностной моделью языка

## Научный вопрос

Можно ли интерпретировать выбранный порядок не просто как эвристику, а как точный порядок вероятности некоторой корректно нормированной модели?

## 4.1. Фиксированный спектр вероятностей

Выбирается вектор:

\[
\alpha=
(\alpha_0,\ldots,\alpha_{255}),
\]

где:

\[
\alpha_r>0,
\qquad
\sum_r\alpha_r=1.
\]

Для каждого префикса модель задаёт только перестановку символов.

Условная вероятность определяется как:

\[
Q_\Pi(x_i=a\mid x_{<i}=p)
=
\alpha_{\pi_p^{-1}(a)}.
\]

Поскольку \(\pi_p\) — перестановка:

\[
\sum_{a\in\Sigma}
Q_\Pi(a\mid p)=1.
\]

Следовательно, это корректная авторегрессионная вероятностная модель.

## Теорема 4. Вероятность через латентные слоты

Для:

\[
z=T_\Pi^{-1}(x)
\]

полная вероятность страницы равна:

\[
Q_\Pi(x)=
\prod_{i=1}^{L}\alpha_{z_i}.
\]

Если выбрать:

\[
\alpha_r=
\frac{\exp(-\beta c(r))}
{Z},
\]

где

\[
Z=
\sum_{r=0}^{255}
\exp(-\beta c(r)),
\]

то:

\[
Q_\Pi(x)=
Z^{-L}
\exp(-\beta W(z)).
\]

Следовательно:

\[
W(z_1)<W(z_2)
\quad\Longleftrightarrow\quad
Q_\Pi(T_\Pi(z_1))
>
Q_\Pi(T_\Pi(z_2)).
\]

Таким образом, порядок по энергии является **точным порядком вероятности внутри специально построенной модели**.

Человеческая осмысленность остаётся приближённой, но математическое утверждение о вероятности становится точным.

## 4.2. Проекция существующей модели на фиксированный спектр

Пусть внешняя языковая модель для контекста \(p\) выдаёт распределение:

\[
P_p(a).
\]

Отсортируем вероятности:

\[
P_p^\downarrow(0)\ge
P_p^\downarrow(1)\ge\ldots\ge
P_p^\downarrow(255).
\]

Для фиксированного вектора \(\alpha\) оптимальная перестановка в смысле минимизации перекрёстной энтропии сопоставляет:

- наибольшую вероятность \(P_p\) с наибольшей \(\alpha_r\);
- вторую с второй;
- и так далее.

Это следует из перестановочного неравенства.

## Предложение 4.1. Оптимальный глобальный спектр

Если контексты \(p\) имеют заданное распределение, то вектор фиксированного спектра, минимизирующий средний прямой KL-разрыв после оптимальной сортировки, равен:

\[
\alpha_r^*
=
\mathbb E_p
\left[
P_p^\downarrow(r)
\right].
\]

Это даёт научно обоснованный способ выбрать базовый спектр, а не подбирать его вручную.

## 4.3. Квантизация спектра

Для точного перечисления желательно иметь небольшие целочисленные стоимости \(c(r)\).

Необходимо решить задачу:

\[
\min_{\beta,c}
D\left(
\alpha^*
\middle\|
\frac{\exp(-\beta c)}
{\sum_j\exp(-\beta c(j))}
\right),
\]

где:

\[
c(r)\in\{0,\ldots,C\}.
\]

Это определяет компромисс между:

- точностью приближения языковой модели;
- числом энергетических оболочек;
- сложностью exact counting;
- плавностью смыслового градиента.

## 4.4. Ошибка приближения полной страницы

Пусть:

\[
\epsilon(p,r)
=
\left|
-\log P_p^\downarrow(r)
-
\bigl(\beta c(r)+\log Z\bigr)
\right|.
\]

Для страницы \(x=T_\Pi(z)\):

\[
\left|
-\log P(x)
-
\left(
\beta W(z)+L\log Z
\right)
\right|
\le
\sum_{i=1}^{L}
\epsilon(x_{<i},z_i).
\]

Если существует равномерная граница:

\[
\epsilon(p,r)\le\epsilon_{\max},
\]

то:

\[
\left|
-\log P(x)
-
\left(
\beta W(z)+L\log Z
\right)
\right|
\le
L\epsilon_{\max}.
\]

Это не гарантирует человеческое качество, но формально связывает новый точный порядок с исходной языковой моделью.

## Обязательные результаты Stage 4

1. Аналитический оптимум \(\alpha^*\).
2. Измеренный KL-разрыв фиксированного спектра.
3. Оптимальная квантизация \(c(r)\).
4. Оценка ошибки между исходной NLL и латентной энергией.
5. Вывод о том, достаточно ли фиксированного спектра для проекта.

## Критерий завершения

Получен количественный ответ:

> Какую долю качества исходной модели мы теряем из-за требования, чтобы каждый контекст имел один и тот же спектр стоимостей?

Без этого ответа нельзя выбирать окончательную стоимость.

# STAGE 5. Определение того, что должно находиться около нуля

## Научный вопрос

Должны ли около нуля находиться самые вероятные страницы или страницы, наиболее похожие на типичный человеческий текст?

Это не одно и то же.

Исследования генерации показывают, что максимальная вероятность не гарантирует максимального человеческого качества: режимы, стремящиеся к наиболее вероятной последовательности, могут создавать повторы и вырожденный текст. Более человеческие последовательности часто находятся ближе к типичному информационному содержанию модели, а не к её абсолютной моде. citeturn642661view3turn681497search1

Поэтому нельзя автоматически утвердить правило:

```text
самая высокая вероятность → адрес 0.
```

Необходимо сравнить несколько научных гипотез.

## Гипотеза A. Вероятностный порядок

Символы располагаются по убыванию:

\[
P_p(a).
\]

Стоимость возрастает вместе с локальным рангом.

Оболочки располагаются по возрастанию \(W\).

### Возможное достоинство

Порядок имеет наиболее простую вероятностную интерпретацию.

### Главный риск

Начало пространства может быть заполнено:

- повторениями;
- слишком частыми словами;
- пробелами;
- однообразными конструкциями;
- авторегрессионными циклами.

---

## Гипотеза B. Локально-типичный порядок

Для контекста \(p\) вычисляется энтропия:

\[
H_p=
-\sum_aP_p(a)\log P_p(a).
\]

Для каждого символа:

\[
d_p(a)=
\left|
-\log P_p(a)-H_p
\right|.
\]

Символы располагаются по возрастанию \(d_p(a)\).

То есть первыми становятся не самые вероятные символы, а символы с информационным содержанием, близким к ожидаемому для данного контекста.

### Возможное достоинство

Начальные страницы могут быть более разнообразными и менее склонными к повторениям.

### Риск

Локальная типичность не гарантирует глобальной связности текста.

---

## Гипотеза C. Гибридный порядок

Определяется детерминированный локальный балл:

\[
S_p(a)=
\lambda_1
\left|
-\log P_p(a)-H_p
\right|
+
\lambda_2[-\log P_p(a)]
+
R_p(a),
\]

где \(R_p(a)\) содержит штрафы за:

- патологические повторы;
- слишком длинные серии пробелов;
- невозможную пунктуацию;
- невалидные байтовые продолжения;
- резкие переключения алфавита;
- управляющие символы;
- разрушение структуры абзаца.

Затем \(\pi_p\) сортирует все символы по:

\[
(S_p(a),\operatorname{code}(a)).
\]

Точный числовой код символа используется как последний tie-breaker.

### Достоинство

Можно непосредственно оптимизировать воспринимаемое качество.

### Риск

Появляется больше параметров и опасность подгонки под демонстрационные примеры.

---

## Гипотеза D. Типичная оболочка вместо минимальной энергии

Можно сохранить вероятностный порядок символов, но начинать библиотеку не с \(W=0\).

Для модели:

\[
Q(x)\propto e^{-\beta W(x)}
\]

вероятностная масса оболочки:

\[
M_e=
A_eZ^{-L}e^{-\beta e}.
\]

Типичная энергия:

\[
e_*=
\arg\max_e M_e.
\]

Тогда оболочки можно расположить в порядке близости к типичной области:

\[
|e-e_*|.
\]

Это отделяет:

- вероятность отдельной страницы;
- суммарную вероятность класса страниц.

## Обязательное решение Stage 5

Необходимо экспериментально выбрать один из вариантов:

1. вероятность;
2. локальная типичность;
3. гибридный балл;
4. типичная глобальная оболочка;
5. доказанная комбинация этих методов.

## Формальный результат

Должна быть зафиксирована функция:

\[
p\mapsto\pi_p
\]

и порядок оболочек:

\[
\rho.
\]

После фиксации они становятся частью определения `Babel-1`.

## Критерий завершения

Выбранный вариант превосходит альтернативы по заранее определённой процедуре оценки, а не по нескольким красивым страницам.

# STAGE 6. Проверка смыслового градиента и геометрии адресов

## Научный вопрос

Действительно ли низкие адреса статистически более человеческие, а не просто имеют меньшую формальную стоимость?

Это центральная экспериментальная гипотеза проекта.

## 6.1. Операциональное определение человеческого качества

Нельзя использовать одно число от той же модели, которая построила порядок.

Необходимо определить независимый вектор качества:

\[
Q(x)=
\bigl(
Q_{\text{fluency}},
Q_{\text{coherence}},
Q_{\text{nonrepeat}},
Q_{\text{structure}},
Q_{\text{human}}
\bigr).
\]

Компоненты:

- синтаксическая и символьная правдоподобность;
- связность между предложениями;
- отсутствие циклов;
- нормальная структура пробелов и пунктуации;
- сохранение языка;
- человеческие попарные оценки;
- независимый внешний оценщик, не использованный при построении \(\pi_p\).

Термин «смысл» должен быть разложен минимум на:

1. языковую правдоподобность;
2. локальную связность;
3. глобальную связность;
4. семантическую содержательность;
5. отсутствие вырождения.

## 6.2. Сэмплирование оболочек

Для оболочки \(e\):

\[
Z_e\sim\operatorname{Uniform}(S_e),
\]

\[
X_e=T_\Pi(Z_e).
\]

Исследуется распределение:

\[
Q(X_e).
\]

Важно сэмплировать оболочки напрямую, потому что равномерная выборка номера из всего диапазона почти всегда попадёт в огромный шумовой хвост.

## 6.3. Основная статистическая гипотеза

Для упорядоченных оболочек \(e_1,e_2,\ldots\):

\[
\mathbb E[Q(X_{e_1})]
>
\mathbb E[Q(X_{e_2})]
>
\ldots
\]

как минимум на начальном и среднем диапазоне библиотеки.

Более сильная форма — стохастическое доминирование:

\[
\Pr(Q(X_{e_i})\ge t)
\ge
\Pr(Q(X_{e_j})\ge t)
\]

для \(i<j\) и значимого диапазона \(t\).

Строгая монотонность для каждой страницы не требуется.

## 6.4. Необходимые сравнения

Новый порядок сравнивается с:

1. обычным base-256;
2. случайной перестановкой страниц;
3. вероятностной сортировкой;
4. локальной типичностью;
5. бинарной схемой `top-K / остальное`;
6. многоуровневой стоимостью;
7. текущей student-моделью;
8. более сильной teacher-моделью.

## 6.5. Геометрия оболочек

Для каждой оболочки нужно анализировать:

\[
A_e,
\qquad
O_e,
\qquad
\log_2 A_e,
\qquad
\log_2 O_e.
\]

Это отвечает на вопросы:

- сколько страниц находится на каждом уровне качества;
- насколько широк «человеческий бассейн» около нуля;
- виден ли переход качества при изменении порядка адреса;
- не занимает ли первая оболочка практически всё доступное для пользователя начало;
- когда начинается преимущественно случайный текст.

Например, при бинарной стоимости первая оболочка имеет размер:

\[
K^{4096}.
\]

Даже при малом \(K>1\) это колоссальный диапазон.

Это не ошибка, но научно необходимо решить:

> Должно ли всё это пространство иметь один уровень качества или требуется более мелкая стоимость?

## 6.6. Критерии успеха

Исследовательская гипотеза принимается, если одновременно выполнено:

1. Нижние оболочки статистически превосходят raw- и random-базовые линии.
2. Между глубиной и качеством существует устойчивая отрицательная зависимость.
3. Результат воспроизводится на независимых текстовых доменах.
4. Улучшение подтверждается человеческим сравнением.
5. Начало пространства не сводится к нескольким повторяющимся режимам.
6. Русский и английский текст не являются случайными единичными исключениями.
7. Результат сохраняется на длинах существенно больше обучающих примеров.

Доверительный интервал ключевого эффекта должен исключать отсутствие улучшения.

## Отрицательный результат

Если exact rank/unrank работает, но смысловой градиент не подтверждён, математическое ядро не отбрасывается.

Вывод будет таким:

> Биекция доказана, но выбранный локальный порядок недостаточно хорошо приближает человеческое качество.

После этого изменяются \(\pi_p\), \(c(r)\) или \(\rho\), а не фундаментальная конструкция.

# STAGE 7. Исследование разнообразия соседних страниц

## Научный вопрос

Как сделать так, чтобы пользователь, переходя от номера \(n\) к \(n+1\), видел другой текст, а не почти ту же страницу?

## Формальное разделение

Порядок оболочек отвечает за качество.

Перестановка \(P_e\) отвечает за локальное разнообразие.

Поскольку \(P_e\) действует только внутри одной оболочки, она не меняет:

- размер оболочки;
- энергию страницы;
- доказательство покрытия;
- распределение страниц внутри оболочки.

Она меняет только порядок показа.

## Кандидаты

### 1. Тождественный порядок

\[
P_e(u)=u.
\]

Используется как контроль.

### 2. Аффинная перестановка

\[
P_e(u)=
(a_eu+b_e)\bmod A_e,
\]

где:

\[
\gcd(a_e,A_e)=1.
\]

Обратное преобразование существует через мультипликативную обратную величину \(a_e^{-1}\).

### 3. Обратимая сеть Фейстеля

Она может использоваться как перестановка диапазона с детерминированным ключом из спецификации библиотеки.

### 4. Смешивание разрядов

Возможна обратимая перестановка комбинированных:

- позиций отклонений;
- хороших локальных рангов;
- плохих локальных рангов.

## Метрики соседства

Для страниц:

\[
x_n=\operatorname{Unrank}(n)
\]

измеряются:

\[
D_{\text{Hamming}}(x_n,x_{n+1}),
\]

длина общего префикса,

\[
D_{\text{embedding}}(x_n,x_{n+1}),
\]

совпадение n-грамм,

сходство тем и структуры.

## Основной критерий

Необходимо максимизировать типичное различие соседей при сохранении:

- точной обратимости;
- детерминизма;
- принадлежности одной оболочке;
- приемлемой вычислительной сложности.

## Важное ограничение

Перемешивание не должно использовать случайность во время запроса.

Все параметры \(P_e\) являются частью конкретного издания библиотеки.

## Критерий завершения

Выбрана одна доказуемо обратимая схема, которая статистически повышает разнообразие соседей относительно лексикографического порядка.

# STAGE 8. Условное расширение выразительности

Эта стадия выполняется **только в том случае**, если Stage 4–6 показывают, что фиксированного спектра стоимостей недостаточно.

Нельзя переходить к ней заранее.

## Проблема фиксированного спектра

В базовой модели каждый контекст имеет один и тот же набор условных вероятностей:

\[
\alpha_0,\ldots,\alpha_{255}.
\]

Меняется только соответствие вероятностей символам.

Но естественный язык имеет контексты разной определённости:

- после некоторых префиксов продолжение почти однозначно;
- после других возможны десятки равноправных продолжений.

Фиксированный спектр не может идеально описать оба случая.

## Расширение 8A. Позиционно-зависимые спектры

Можно определить:

\[
c_i(r)
\]

для каждой позиции или класса позиций.

Тогда:

\[
W(z)=
\sum_i c_i(z_i),
\]

а число страниц энергии \(e\):

\[
A_e=
[t^e]
\prod_{i=1}^{L}
\left(
\sum_r t^{c_i(r)}
\right).
\]

Биекция сохраняется.

Подсчёт остаётся независимым от текстового контекста.

## Расширение 8B. Периодические или блочные спектры

Можно иметь разные стоимости для:

- начала страницы;
- середины;
- конца;
- начала абзаца;
- позиции внутри 256-символьного блока.

Если расписание зависит только от позиции, exact counting остаётся прямым.

## Расширение 8C. Малое латентное состояние

Вводится конечное множество состояний:

\[
h_i\in H.
\]

Начальное состояние \(h_0\) фиксировано.

На каждом шаге:

\[
x_i=
\pi_{x_{<i},h_{i-1}}(z_i),
\]

\[
h_i=
\delta(h_{i-1},z_i),
\]

\[
W(z)=
\sum_i c(h_{i-1},z_i).
\]

При обратном преобразовании:

1. известен \(h_{i-1}\);
2. известен текстовый префикс;
3. восстанавливается \(z_i\);
4. вычисляется \(h_i\).

Следовательно, треугольная биекция сохраняется.

## Теорема 5. Подсчёт через полиномиальную матрицу

Определим:

\[
M(t)_{h,h'}
=
\sum_{\substack{r:\\
\delta(h,r)=h'}}
t^{c(h,r)}.
\]

Тогда число латентных страниц длины \(L\) и энергии \(e\) получается как коэффициент:

\[
[t^e]
\mathbf e_{h_0}^{\mathsf T}
M(t)^L
\mathbf 1.
\]

Это возвращает конечное состояние в exact counting, но состояние является:

- маленьким;
- специально сконструированным;
- независимым от полного состояния языковой модели.

## Принципиальное отличие от старого пути

Старый подход пытался считать состояния самого текста или student-модели.

Новый условный подход считает только небольшой латентный автомат.

Языковая модель всё ещё влияет только на перестановку символов и не расширяет пространство DP.

## Критерий перехода на Stage 8

Расширение разрешено только при наличии количественного результата:

\[
\mathcal E_{\text{fixed spectrum}}
>
\text{заранее заданной допустимой ошибки}
\]

или при статистически значимом провале смыслового градиента.

## Критерий завершения

Найдено минимальное число состояний \(|H|\), после которого качество достигает требуемого уровня.

Выбирается минимальная достаточная модель, а не максимальная доступная.

# STAGE 9. Масштабирование, точная арифметика и воспроизводимость

## Научный вопрос

Можно ли получить одинаковый адрес на любой машине спустя годы после публикации библиотеки?

## 9.1. Целочисленный порядок кандидатов

Плавающие оценки модели нельзя считать окончательной спецификацией.

Необходимо определить один из вариантов:

1. квантованные целочисленные логиты;
2. целочисленные переходные стоимости;
3. точные рациональные оценки;
4. каноническое округление;
5. стабильный tie-break по байту.

Перестановка должна быть бит-в-бит воспроизводима.

## 9.2. Точные размеры оболочек

Все значения:

\[
A_e,
\qquad
O_e,
\qquad
N(m,e)
\]

вычисляются как произвольные целые числа без:

- float;
- логарифмических приближений;
- вероятностных округлений;
- усечения старших разрядов.

Приближённые числа допустимы только для интерфейса, но не для `rank/unrank`.

## 9.3. Версионирование

Адрес должен включать идентификатор издания:

```text
Babel-1:
  domain specification;
  alphabet hash;
  page length;
  model hash;
  scoring rule;
  cost vector;
  shell order;
  mixing algorithm;
  rank.
```

Замена модели создаёт новое издание:

```text
Babel-2
```

а не незаметно меняет старую библиотеку.

## 9.4. Набор канонических тест-векторов

Спецификация должна включать:

- адрес 0;
- адрес 1;
- последний адрес;
- границы оболочек;
- начало и конец нескольких оболочек;
- страницы из нулевых байтов;
- страницы из байтов 255;
- русский UTF-8;
- английский ASCII;
- невалидный UTF-8;
- случайные страницы;
- страницы с повторами.

Для каждого фиксируются:

```text
input page;
latent z;
energy;
shell;
local rank;
global rank;
restored page.
```

## 9.5. Независимые реализации

Нужно получить минимум две независимые реализации математической спецификации.

Они обязаны совпасть на всех тест-векторах и случайных циклах.

## Критерий завершения

На длине \(L=4096\):

\[
\operatorname{Rank}(\operatorname{Unrank}(n))=n
\]

для:

- границ;
- специальных чисел;
- большого случайного набора.

И:

\[
\operatorname{Unrank}(\operatorname{Rank}(x))=x
\]

для:

- человеческих текстов;
- произвольных байтов;
- случайных страниц;
- невалидных строк.

Не допускается ни одной ошибки.

# STAGE 10. Финальная научная валидация и заморозка `Babel-1`

## Научный вопрос

Какие утверждения после исследования можно публиковать как доказанные, а какие — только как эмпирически подтверждённые?

## Доказуемые утверждения

После прохождения предыдущих стадий допустимо утверждать:

1. Пронумерованы все \(2^{32768}\) страницы.
2. Ни одна страница не потеряна.
3. Ни одна страница не повторяется.
4. По номеру страница восстанавливается точно.
5. По странице номер восстанавливается точно.
6. Порядок страниц является точным порядком выбранной математической функции.
7. Версия библиотеки воспроизводима.

## Эмпирические утверждения

Они публикуются вместе с протоколом оценки:

1. Начальные оболочки чаще похожи на человеческий текст.
2. Глубина статистически связана с ухудшением качества.
3. Выбранный порядок превосходит base-256 и случайную перестановку.
4. Перемешивание повышает разнообразие соседних страниц.
5. Результаты устойчивы для нескольких языков и доменов.

## Запрещённые утверждения

Без отдельного доказательства нельзя говорить:

- что получен объективный порядок смысла;
- что каждая меньшая страница осмысленнее каждой большей;
- что модель понимает истинность текста;
- что все человеческие тексты образуют один непрерывный начальный диапазон;
- что порядок не зависит от выбранного языка, корпуса и модели;
- что адрес является универсальным вне конкретного издания библиотеки.

# 12. Главные исследовательские вопросы

## RQ1. Биективность

Достаточно ли контекстных перестановок для точной обратимости полной страницы?

Ожидаемый ответ: да, по Теореме 1.

## RQ2. Точный подсчёт

Можно ли считать оболочки независимо от языковой модели?

Ожидаемый ответ: да, если стоимость принадлежит латентному слоту, а не реальному символу.

## RQ3. Полный глобальный ранг

Можно ли получить exact rank/unrank всех \(2^{32768}\) страниц без подсчёта языковых состояний?

Ожидаемый ответ: да, через композицию оболочек и контекстной биекции.

## RQ4. Выразительность

Насколько хорошо фиксированный спектр условных вероятностей приближает реальную языковую модель?

Ответ должен быть получен через KL-проекцию и эксперименты.

## RQ5. Определение начала

Что даёт более человеческие страницы около нуля:

- максимальная вероятность;
- локальная типичность;
- типичная глобальная энергия;
- гибридный порядок?

Ответ эмпирический.

## RQ6. Градиент

Снижается ли человеческое качество при движении по упорядоченным оболочкам?

Ответ эмпирический и статистический.

## RQ7. Разнообразие

Можно ли сделать соседние страницы различными, не разрушая оболочки?

Ожидаемый ответ: да, через \(P_e\), но конкретная схема выбирается экспериментально.

## RQ8. Минимальная сложность

Нужен ли конечный латентный автомат или достаточно независимых слотов?

Ответ определяется только после проверки фиксированного спектра.

## RQ9. Воспроизводимость

Можно ли гарантировать одинаковые адреса на разных платформах?

Ответ должен быть подтверждён независимыми реализациями.

# 14. Самая важная формулировка для следующего агента

Полная инженерная декомпозиция должна строиться не вокруг задачи:

```text
посчитать точное место страницы
по энергии существующей языковой модели
с учётом всех контекстных состояний.
```

Она должна строиться вокруг другой математической конструкции:

```text
1. Точно перечислить латентные последовательности по простой стоимости.

2. Для каждого текстового контекста переставить все 256 символов
   между заранее известными латентными слотами.

3. Использовать тот факт, что перестановка не меняет
   количества вариантов каждой стоимости.

4. Получить точный глобальный rank/unrank
   как композицию двух биекций.

5. Научно выбрать такую перестановку и стоимость,
   при которых начало библиотеки статистически выглядит человеческим.
```

Главная недостающая научная работа — не новый способ считать огромное состояние исходной модели.

Главная недостающая работа состоит из трёх результатов:

\[
\boxed{
\text{доказать контекстную перестановочную биекцию}
}
\]

\[
\boxed{
\text{выбрать и доказать точное перечисление латентных оболочек}
}
\]

\[
\boxed{
\text{экспериментально установить, какой порядок слотов создаёт человеческое начало}
}
\]

После получения этих результатов другой агент сможет безопасно выполнить полную техническую декомпозицию, не меняя математическую архитектуру проекта по ходу реализации.
