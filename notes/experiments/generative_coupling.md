# Можно ли отдать начало библиотеки языковой модели?

В первом слепом опыте Babel-1 связное высказывание получили 0 из 32 ранних и 0 из 32 глубоких фрагментов. У каталога есть 961 читаемая страница из готовых абзацев. Новый опыт проверяет, можно ли получать по ранним номерам разнообразные, заново сочинённые страницы и возвращать номер по произвольному тексту. [Опыт с Babel-1](babel1_readability.md)

## Как номер превращается в страницу

Записываем номер в виде 4096 цифр по основанию 256. Делим их на две равные части `L` и `R`. Функция `F(R)` по зерну сочиняет первую половину. Функция `G(U)` продолжает уже написанный текст. Каждая возвращает ровно 2048 индексов знаков исходного алфавита. Операция `^` означает побитовое исключающее ИЛИ между соответствующими индексами.

```text
unrank: U = L ^ F(R)      V = R ^ G(U)      страница = U || V
rank:   R = V ^ G(U)      L = U ^ F(R)      номер    = L || R
```

Повторное применение одной и той же маски возвращает исходные байты. Сначала восстанавливается `R`, затем `L`. Это доказывает взаимно однозначное соответствие для всех `2^32768` страниц даже при совпадающих ответах генератора. Нужно уметь повторить каждое предсказание в точности. Дискретные обратимые преобразования такого типа описаны в литературе. В прежнем плане Babel перестановка Фейстеля перемешивала номера внутри оболочки. Здесь предсказания меняют текст целой страницы. [Tran et al., Discrete Flows](https://arxiv.org/abs/1905.10347) · [Исходная программа Babel](../../ROADMAP.md)

При номере меньше `2^64` половина `L` нулевая. В `R` могут отличаться от нуля только последние восемь цифр. Значит, **первые 4088 знаков совпадают с текстом, который сочинил генератор для этого номера**. На номере ноль совпадают все 4096. Это даёт раннюю область без списка заготовок. У равномерно выбранного адреса по-прежнему равномерное распределение страниц, как у любой перестановки.

## Что уже проверено

Запуск из корня репозитория требует только Python 3.10 или новее.

```bash
python experiments/generative_coupling.py
```

Перебраны все 65 536 двузначных страниц в обоих направлениях. Для полных страниц проверены граничные номера, произвольные страницы и гарантированная длина совпадающего начала. Предсказатели в этом тесте вычисляют байты детерминированно. Есть и контроль на повторы. Если предсказатель всегда выдаёт один текст, первые 32 страницы имеют 32 разных адреса и совпадают в первых 4095 знаках. Поэтому точная обратимость и число разных хешей сами по себе ничего не говорят о разнообразии чтения. [Исполняемый прототип](../../experiments/generative_coupling.py)

## Следующий эксперимент и критерии решения

1. Подключить одну локальную модель, умеющую писать по-русски и по-английски. Зафиксировать веса, токенизатор, подсказки, способ выбора токенов, обработку конца текста и перевод в 256 знаков. Проверить одинаковые хеши страниц после перезапуска на двух машинах. Заморозить версию, выборку и правила оценки до генерации.
2. **От номера к тексту.** Взять адреса 0–63 и по 64 номера из четырёх диапазонов с числом значащих битов 64, 8192, 16384 и 32768. Сопоставить с Babel-1 и raw на тех же номерах. В случайном порядке дать трём читателям полные страницы вместе с авторской прозой и контрольными страницами, у которых продолжения переставлены между разными началами. Для положительной оценки большинство должно суметь кратко пересказать одну мысль и указать, где во второй половине она продолжается. Отдельно считать почти дословные повторы между страницами. Предлагаемый порог для адресов 0–63 — преимущество минимум 20 процентных пунктов над Babel-1, нижняя граница 95%-го интервала парной разницы выше нуля. Доли по промежуточным глубинам покажут форму зависимости.
3. **От текста к номеру.** Взять отдельно 64 русские и 64 английские полные страницы, исключённые из настройки, из нескольких произведений. Для каждой переставить предложения с сохранением всех знаков и длины. Проверить, как часто оригиналу достаётся меньший номер. Считать победы по парам и интервал с группировкой по произведениям. Если интервал включает 50%, преимущество для чужой прозы остаётся открытым, даже если сгенерированное начало читается хорошо.

При провале прямой проверки сначала исследовать самого генератора, сравнив его текст со страницей на том же зерне. При провале обратной проверки измерить на тех же парах длину обратимого сжатия, учитывающего контекст. Короткое восстанавливаемое описание страницы даёт вторую гипотезу для назначения ей малого номера. Строгая сортировка по полной энергии прежней модели остаётся самостоятельной математической задачей.
