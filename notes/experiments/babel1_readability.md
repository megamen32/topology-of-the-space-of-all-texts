# Связность текста по первым адресам Babel-1

Среди фрагментов с адресов 0–31 связное высказывание встретилось **0 раз из 32**. Столько же получили для случайных адресов в глубине библиотеки. Оба оценщика распознали все **16 из 16** отрывков Достоевского. [Анонимные тексты](babel1_readability_blind.jsonl) · [Разметка по карточкам](babel1_readability_ratings.csv)

## Условия проверки 20 ноября 2026 года

Проверяем исходную модель Markov-5 на страницах длиной 4096 символов. Основной вопрос — чаще ли связны фрагменты первых 32 страниц Babel-1, чем фрагменты глубоких страниц и страниц в обычной нумерации. Участие каталога заранее составленных абзацев исключено из выборки.

Берём все адреса от 0 до 31, ещё 32 случайных адреса из остальной части нулевой оболочки и 32 случайных адреса за её пределами. В каждой группе открываем те же численные адреса в обычном режиме raw. Для каждого наблюдения заранее выбираем окно длиной 240 символов. В парных сравнениях позиция окна совпадает. Зерно выборки и перемешивания — `20261120`.

Добавляем 16 фрагментов «Белых ночей» Ф. М. Достоевского для контроля разметки. Они берутся из опубликованного корпуса и учитываются отдельно. Каждому оценщику выдаём только случайный идентификатор и текст.

До открытия страниц план из 208 наблюдений получил SHA-256 `311b0b304b5791039d4b7521a286b0d35163c867e3d364e2b7eef68ebba7dda8`.

**Правило разметки.** Ставим «да», если внутри окна есть хотя бы одно понятное высказывание на русском или английском с пятью или более синтаксически связанными словами. Из высказывания должно быть понятно, кто что делает, что описано или как связаны предметы. Оборванные края окна допустимы. Для отдельных узнаваемых слов, повторов и шума ставим «нет». Для основного подсчёта нужно согласие двух оценщиков. Расхождения учитываем отдельно.

## Результаты

Разметку выполнили два независимых запуска одной ИИ-модели в отдельных чатах. Каждый получил один и тот же файл с карточками и правило оценки. Ключ с адресами и группами хранился отдельно. Оценщики совпали на всех 208 карточках.

| Группа адресов | Babel-1, связных окон | Raw на тех же адресах | Доля букв в окнах Babel-1 |
|---|---:|---:|---:|
| Все адреса 0–31 | 0/32 | 0/32 | 94,3% |
| Случайные адреса из остальной части нулевой оболочки | 0/32 | 0/32 | 94,5% |
| Случайные адреса за пределами нулевой оболочки | 0/32 | 0/32 | 47,3% |

Доля букв вычислена по `str.isalpha()` на всех символах выбранных окон. Например, у адреса № 0 со смещения 1773 встречается «инраоеанtелтлсе веакиaикtрo». Низкая энергия заметно меняет состав знаков. В этой выборке измеримого преимущества по связности у неё не обнаружилось.

У каждой страницы проверено одно окно длиной 240 символов. Выборка за пределами нулевой оболочки равномерна по адресам, поэтому самые многочисленные оболочки представлены чаще. Вывод относится к этому изданию Markov-5, этим окнам и данной разметке. Для оценки людьми те же карточки доступны без ключа. Следующую модель можно сравнить на новых адресах по тому же правилу, сохранив это издание как базу сравнения.

## Как повторить

Контрольный прогон выполнен на CPython 3.10.12. Запустите команды из корня репозитория после установки зависимостей. Программа открывает полные страницы, выбирает зафиксированные окна и отдельно записывает группы, адреса, смещения и хеши страниц в `key.json`. `cmp` сверяет все предъявленные тексты байт в байт.

```bash
work=$(mktemp -d)
python experiments/evaluate_babel_1_shell.py blind \
  --seed 20261120 --per-group 32 --fragment-length 240 --out "$work/run"
cmp "$work/run/blind.jsonl" notes/experiments/babel1_readability_blind.jsonl
```

SHA-256 файла карточек — `e9f5584cc6a4ba4d4e8e235c95b2d856ac2f2a2ed17b43b14afab24dd18a8140`. В CSV колонки `rater_a` и `rater_b` содержат исходные оценки. Единица означает, что высказывание удовлетворяет правилу. Строки `known_prose` образуют положительный контроль.
