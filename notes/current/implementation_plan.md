# Как повторить проверки библиотеки

## Проверка Qwen3

Издание `babel-qwen3-ref-v1` прошло проверку на двух серверах и в публичном Search. Эти действия повторяют браузерную проверку 20 ноября 2026 года. [Вход в режим Qwen](https://babel.bezrabotnyi.com/search.html?mode=qwen_reference_v1) · [Номера и SHA-256 для сверки](../experiments/qwen_reference_verification.json)

1. Введите `41` и нажмите «Открыть страницу». Скачайте файл UTF-8 и сверьте его SHA-256 с эталоном. Кнопка «Найти номер страницы» по открытому тексту должна вернуть 41.
2. Загрузите файл UTF-8 из всех 256 знаков алфавита в исходном порядке, повторённых 16 раз подряд без разделителя. Нажмите «Найти номер страницы». Сверьте шестнадцатеричный номер целиком со значением `page_first.address_hex` в результатах стенда. [Алфавит издания](../../models/top256_alphabet/alphabet_top256.json)
3. Введите «Привет лол 😂 hello». Здесь 18 знаков, включая эмодзи. Поиск добавит справа 4078 пробелов. Откройте полученный номер и скачайте страницу, чтобы проверить строку целиком.

Слепое чтение завершено. Чтобы повторить подсчёт по исходным оценкам и проверить цитаты, выполните из корня проекта `python3 experiments/evaluate_reference_readability.py verify`. [Зарегистрированный протокол](../experiments/reference_readability/protocol.json) · [Результаты чтения](../experiments/reference_readability/result.md)

## Как повторить проверку сайта

- Выполнить GET для корня, генераторов и читалки на обоих доменах. Сверить конечные заголовки и пройти по видимым ссылкам с главной к генераторам и оттуда в читалку. [Карта сайта](../../README.md#карта-сайта)
- В генераторе повторить выбор с одним seed, изменить seed, затем набрать свой текст и нажать Score generated. [Контрольные значения для шести режимов](../../site/README.md#шесть-режимов-генератора)
- В Search проверить преобразование «текст → номер → страница» для raw и короткого кластера. Для блочной композиции открыть номер и восстановить его по полной странице. В читалке проверить границу каталога и обе стороны адресации Babel-1. [Результаты публичной проверки](status.md#что-проверено-на-публичном-сайте)
- При изменении обычной адресации дополнительно проверять граничные номера, преобразование `page64` в десятичную запись и обратно, переходы читалки, копирование адреса и отображение на телефоне. [Запуск и проверки из чистой копии](../../README.md#локальный-запуск)

## Справка о полном порядке по стоимости

В коротком кластерном опыте есть прямой счётчик и сверка блочного подсчёта с ним. Метод `verify_against_raw_dp` сравнивает число страниц для каждого значения стоимости и проверяет покрытие пространства. [Счётчик и сверка](../../experiments/cluster_chunk_counting.py)

В этом опыте страницу длиной 4096 знаков собирали из 16 блоков по 256. [Математические критерии ранних опытов](open_problems.md#4-проверки-нового-порядка)
