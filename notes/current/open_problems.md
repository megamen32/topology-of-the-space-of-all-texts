# Открытые задачи

## 1. Порядок всех страниц по стоимости исходной модели

Для raw, каталога и бинарных оболочек Babel-1 уже работают прямое и обратное преобразования между номером и страницей. Предстоит построить такой же способ адресации для порядка по суммарной стоимости всех переходов исходной модели на 4096 знаках.

## 2. Масштабирование точного подсчёта

В коротком кластерном опыте используется разреженное динамическое программирование. Для подсчёта по полной стоимости на 4096 знаках предстоит решить несколько задач.

- Сжать таблицы числа страниц для каждого значения стоимости.
- Разбить страницу на блоки с передачей состояния модели через границу.
- Организовать хранение больших таблиц во внешней памяти.
- Сохранить точность при работе с большими целыми числами.
- На малых длинах сверить результат с полным перебором.

## 3. Читаемость

В первом слепом опыте ИИ-модель оценила по одному фрагменту с каждой выбранной страницы. Отдельно предстоит проверить, как те же фрагменты оценят люди. Открыт и вопрос о том, как часто связная речь встречается на полных страницах во всём адресном пространстве. [Протокол первого опыта](../experiments/babel1_readability.md)

## 4. Проверки нового порядка

Для исследуемого порядка по полной стоимости нужны четыре воспроизводимые проверки.

- Все страницы учтены по одному разу.
- Выполнены `rank(unrank(n)) = n` и `unrank(rank(page)) = page`.
- Стоимость возрастает при переходе к следующему уровню.
- Подсчёт по блокам и прямой подсчёт дают одинаковое число вариантов.

## 5. Названия режимов

В интерфейсе важно указывать, откуда взялся номер. Raw обозначает обычную запись по алфавиту, номер каталога учитывает перестановку готовых страниц, а номер Babel-1 — оболочку и место внутри неё. У Atlas собственные координаты литературных примеров. [Научная программа и критерии проверки](../../ROADMAP.md)
