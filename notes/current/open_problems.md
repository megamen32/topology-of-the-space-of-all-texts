# Открытые задачи

## 1. Порядок всех страниц по стоимости исходной модели

Для 4096 знаков уже есть точная композиция номеров кластерных блоков. Открыт другой вопрос — как присвоить странице номер по суммарной контекстной стоимости всех переходов, включая переходы между блоками. [Устройство кластерных блоков](architecture.md#кластерные-блоки)

## 2. Масштабирование точного подсчёта

В коротком кластерном опыте уже можно сравнить числа страниц по уровням стоимости при прямом и блочном подсчёте. Для перехода к полной длине предстоит решить несколько задач.

- Сжать таблицы числа страниц для каждого значения стоимости.
- Сохранить передачу состояния через границу блока при увеличении длины страницы.
- Организовать хранение больших таблиц во внешней памяти.
- Сохранить точность при работе с большими целыми числами.
- На малых длинах сверять новые способы подсчёта с полным перебором.

## 3. Читаемость

В первом слепом опыте с Babel-1 ИИ-модель оценила по одному фрагменту с каждой выбранной страницы. Согласятся ли люди с этими оценками? Как часто связная речь встречается на полных страницах во всём адресном пространстве? [Протокол первого опыта](../experiments/babel1_readability.md)

## 4. Проверки нового порядка

Для исследуемого порядка по полной стоимости нужны четыре воспроизводимые проверки.

- Все страницы учтены по одному разу.
- Выполнены `rank(unrank(n)) = n` и `unrank(rank(page)) = page`.
- Стоимость возрастает при переходе к следующему уровню.
- Подсчёт по блокам и прямой подсчёт дают одинаковое число вариантов.

## 5. Связность и адреса в эксперименте с LLM

Как часто вторая половина страницы Qwen3 развивает первую на ранних и далёких адресах? Для такого сравнения нужен побайтовый эталон. Получает ли авторский текст меньший номер, чем тот же текст с переставленными предложениями? В опыте с «Белыми ночами» проверили одну пару.
