# Текущий статус

Основная читалка открывает страницу № 0 каталога. Домен `babel.bezrabotnyi.com` перенаправляет запросы на `all.bezrabotnyi.com` с кодом 308. [Открыть библиотеку](https://all.bezrabotnyi.com/library.html)

## Что работает в читалке

| Режим | Что проверено |
| --- | --- |
| Обычный адрес (raw) | Нормализованная страница из 4096 знаков получает номер в системе с основанием 256. По номеру можно открыть страницу. Читалка показывает адрес в десятичной записи и в формате `page64`. |
| Читаемое начало | Из 31 русского абзаца составлена 961 упорядоченная пара. Номера 0–960 заняты этими страницами. С № 961 действует обычная адресация алфавита каталога с учётом обмена местами. Все страницы доступны по одному разу. |
| Babel-1 | Нумерация по бинарным оболочкам и контекстная перестановка знаков обратимы. В API и публичной читалке проверены переходы от номера к странице и обратно. |

Для обычного адреса `site/data/model.json` и `models/student_fsm_v1` используют нормализованный алфавит. Алфавит каталога и Markov-5 совпадает с полем `alphabet` в `735d351:site/data/model.json` и содержит 54 заглавные буквы. Номер нужно хранить вместе с режимом, в котором он получен.

## Как восстановить исходную таблицу Markov-5

В чистой копии проверены исходный индекс, все 2 664 834 строки таблицы и все девять эталонных страниц Babel-1. Читалка использует упакованные строки напрямую. Чтобы получить побайтовую копию исторической матрицы и проверить её, выполните из корня репозитория следующие команды.

```bash
unzip -p models/top256_markov5/markov5_rows.zip > /tmp/markov5_rows_u16.bin
sha256sum /tmp/markov5_rows_u16.bin
```

SHA-256 исходной матрицы — `2268971985cd4b2b56ab41cdb7f2d8beb4a417d8d397be532ffec801eceb4567`.

## Что показали другие опыты

В кластерном опыте для длин до 256 знаков можно точно упорядочить страницы по сумме стоимостей переходов. При равной стоимости действует порядок знаков алфавита. Композиция из 16 таких блоков даёт обратимую нумерацию для 4096 знаков по номерам блоков. В API сохранились поиск, оценка стоимости, подсчёт и переход к соседнему номеру. Atlas собирает литературные примеры из заготовок.

## Результаты слепой проверки

Для каждой страницы Babel-1 и raw заранее выбрали один фрагмент из 240 знаков при длине страницы 4096. ИИ-модель видела фрагменты без адресов. Оценка «да» означала, что во фрагменте есть понятное высказывание хотя бы из пяти связанных слов.

| Источник фрагмента | Получили «да» / всего |
| --- | ---: |
| Babel-1, адреса 0–31 | 0/32 |
| Babel-1, случайные адреса из остальной части нулевой оболочки | 0/32 |
| Babel-1, случайные адреса за пределами нулевой оболочки | 0/32 |
| Raw, те же адреса | 0/96 |
| «Белые ночи» Достоевского | 16/16 |

На адресах Babel-1 от 0 до 31 доля букв во фрагментах составила 94,3%, в выборке за пределами нулевой оболочки — 47,3%. Два запуска одной ИИ-модели провели изолированно. Их оценки совпали на 208 из 208 карточек. [Протокол и правила разметки](../experiments/babel1_readability.md)

## Что остаётся проверить

Независимая слепая разметка людьми — отдельный эксперимент. Остаётся выяснить, как часто связная речь встречается на полных страницах во всём адресном пространстве и насколько похожи по содержанию соседние страницы. Порядок всех страниц по полной стоимости исходной языковой модели остаётся исследовательской задачей.
