# Текущий план

Читалка уже открывает обычные адреса, каталог и номера Babel-1. [Открыть библиотеку](https://all.bezrabotnyi.com/library.html) · [План реализации](implementation_plan.md)

## Этапы 1–3. Обычная адресация и кластерный опыт

Обычная адресация охватывает все страницы из 4096 знаков нормализованного алфавита. Для страниц длиной до 256 знаков реализована отдельная сортировка по стоимости кластерных переходов. Из 16 таких блоков можно собрать обратимую нумерацию полной страницы. Блоки при этом упорядочены по своим номерам.

## Этап 4. Бинарные оболочки Babel-1 — реализовано

Для каждого контекста модель упорядочивает все 256 знаков исходного алфавита. Оболочка `s` содержит страницы, на которых ровно `s` раз выбран знак за пределами первых 16. Размер оболочки равен `C(4096, s) × 16^(4096 − s) × 240^s`. Внутри неё действует обратимая перестановка номеров. Для этого порядка выполнены полный перебор на малых алфавитах и проверки прямого и обратного преобразования на полной длине. Режим доступен в API и читалке.

## Этап 5. Читабельность первых страниц

- Первый слепой опыт завершён. Два запуска одной ИИ-модели дали одинаковые оценки всем 208 фрагментам. [Протокол первого сравнения](../experiments/babel1_readability.md)
- Открытая задача — провести независимую слепую разметку с участием людей. Более широкая научная проверка включает отложенную русскую и английскую прозу.
- Для конечного каталога возможен другой шаг — расширить набор абзацев. При расширении проверить уникальность страниц, обратимость их адресов и первый номер за границей каталога. Сейчас эта граница проходит между № 960 и № 961.

## Исследовательская ветка

Первый кандидат на следующий опыт — дать языковой модели сочинять две половины страницы и обратимо записывать номер в её предсказаниях. Прототип прошёл полный перебор малого пространства. Решение о развитии зависит от двух проверок — связности сгенерированных страниц и адресов независимой авторской прозы. [Конструкция, доказательство и план опыта](../experiments/generative_coupling.md)

Для глобального порядка по полной стоимости исходной модели нужно научиться считать продолжения с учётом состояния модели на границе блоков. Критерии математической проверки и проверки качества на текстах заданы в научной программе. [Научный ROADMAP](../../ROADMAP.md)
