# Текущий план

## Сравнить полные страницы

Сравнить страницы из эксперимента с LLM с образцами двух student-конфигураций, которые выделились в ранних опытах. Состав участников и основания для их выбора зафиксированы в [результатах сравнений](status.md#что-удавалось-ранним-моделям). Условия и статус полностраничной сверки LLM ведутся в [протоколе эксперимента](../experiments/generative_coupling.md).

Первый вопрос — может ли читатель найти связное высказывание на полной странице и в каких вариантах такие страницы встречаются чаще. Второй касается адресации — получают ли независимые авторские тексты меньшие номера, чем те же тексты с переставленными предложениями. Для первого вопроса нужны слепые оценки текстов, для второго — номера в одном и том же порядке. [План сравнения](implementation_plan.md#сравнение-генераторов)

## Проверить выводы о читаемости

В завершённой слепой проверке Babel-1 два запуска ИИ-модели оценивали короткие фрагменты. Открыты независимая разметка людьми и проверка на отложенной русской и английской прозе. [Протокол первого сравнения](../experiments/babel1_readability.md)

## Продолжить исследование точной нумерации

Для порядка по полной контекстной стоимости 4096 знаков нужно учитывать состояние модели на границе блоков.
