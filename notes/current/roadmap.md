# Текущий план

## Qwen3 с обратимой нумерацией

Для открытия страницы достаточно одной машины. Второй сервер нужен для независимой проверки воспроизводимости.

1. Получить побайтовый эталон для той же Qwen3 1.7B. На серверах 44 и 88 после перезапуска восстановить исходные номера по эталонным страницам. Для независимо заданного текста вычислить номер и по нему восстановить все байты.
2. На этом издании вслепую сравнить полные страницы с ранних и далёких адресов. Измерить, как часто встречается читаемый абзац и как часто вторая половина развивает событие или мысль из первой.
3. После измерений добавить в интерфейс открытие страницы Qwen3 по номеру и поиск номера по тексту.
