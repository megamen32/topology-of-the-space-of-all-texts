# Состояние библиотеки

## Цель

У каждой страницы из 4096 знаков выбранного алфавита есть точный адрес.
Проверяем, можно ли расположить страницы так, чтобы на малых номерах чаще встречалась связная речь.

## Что работает

- Raw переводит страницу нормализованного алфавита в 32768-битное число и обратно.
- Babel-1 использует исходный алфавит, контекстную перестановку Markov-5 и точную нумерацию оболочек. Энергия равна числу позиций с выбором за пределами первых 16 символов модели.
- Каталог ставит в начало 961 страницу из 31 готового абзаца. Конечные перестановки сохраняют адресацию всех остальных страниц. Литературный маршрут отдельно открывает подписанные цитаты.
- Каноническая читалка — https://all.bezrabotnyi.com/library.html. Проверка внешнего входа и перенаправления с babel.bezrabotnyi.com зафиксирована 17 августа 2026 года.
- 20 ноября найдены исходные файлы на сервере 100. Алфавит, индекс и развёрнутая таблица из 2 664 834 строк сверены по SHA-256. В Git строки упакованы по блокам без потерь. Есть контрольные отпечатки девяти страниц исторической версии.

## Исследовательская граница

- Порядок адресов внутри одной оболочки обратим. Соседство номеров само по себе ничего не говорит о сходстве содержания.
- Ранние опыты с Markov-5 давали последовательности букв. Из 24 конфигураций других моделей лучший автоматический балл получил словесный вариант, в его примерах встречались обрывки фраз.
- У кластерной модели есть точный порядок общей стоимости до 256 символов и композиция 16 блоков для страницы длиной 4096. Сквозной порядок по полной контекстной стоимости остаётся открытым.
- Формальная биекция и эмпирическая связность проверяются отдельно. Критерии исследования собраны в [ROADMAP.md](../ROADMAP.md).

## Текущая проверка

Зафиксированы 32 первых адреса, две контрольные группы по 32 адреса, парные страницы raw и литературный контроль. Следующий шаг — разметка по [слепому протоколу](../notes/experiments/babel1_readability.md).
