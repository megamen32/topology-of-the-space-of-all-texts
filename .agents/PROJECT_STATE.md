# Состояние библиотеки

## Цель

У каждой страницы из 4096 знаков выбранного алфавита есть точный адрес.
Проверяем, можно ли расположить страницы так, чтобы на малых номерах чаще встречалась связная речь.

## Что работает

- Raw переводит страницу нормализованного алфавита в 32768-битное число и обратно.
- Babel-1 использует исходный алфавит, контекстную перестановку Markov-5 и точную нумерацию оболочек. Энергия равна числу позиций с выбором за пределами первых 16 символов модели.
- Каталог ставит в начало 961 страницу из 31 готового абзаца. Конечные перестановки сохраняют адресацию всех остальных страниц. Литературный маршрут отдельно открывает подписанные цитаты.
- Главная — https://babel.bezrabotnyi.com/. При проверке 20 ноября HTTP 308 сохранил путь на all.bezrabotnyi.com. На /generate.html работают шесть генераторов по seed, /search.html даёт rank и unrank, /library.html открывает каталог и Babel-1. [Карта сайта](../README.md#карта-сайта)
- 20 ноября найдены исходные файлы на сервере 100. Алфавит, индекс и развёрнутая таблица из 2 664 834 строк сверены по SHA-256. В Git строки упакованы по блокам без потерь. Есть контрольные отпечатки девяти страниц исторической версии.

## Исследовательская граница

- Порядок адресов внутри одной оболочки обратим. Соседство номеров само по себе ничего не говорит о сходстве содержания.
- Повторены 20/20 предложений и 20/20 абзацев исторического B2. В 24 конфигурациях по автоматическому баллу первым был word 0.55. По голосам самого Qwen3-4B лидировал paragraph 0.85/64. Судья почти всегда выбирал левый ответ. [История студентов и границы оценок](../notes/current/status.md)
- У кластерной модели есть точный порядок общей стоимости до 256 символов и композиция 16 блоков для страницы длиной 4096. Сквозной порядок по полной контекстной стоимости остаётся открытым.
- Формальная биекция и эмпирическая связность проверяются отдельно. Критерии исследования собраны в [ROADMAP.md](../ROADMAP.md).

## Результат проверки 20 ноября 2026 года

Чистая копия прошла сверку файлов, тест каталога, самопроверку оболочек и тест API с девятью историческими адресами.
Два изолированных ИИ-оценщика совпали на 208 карточках. Связные фрагменты Babel-1 — 0/32 на первых адресах, 0/32 в остальной части нулевой оболочки и 0/32 за её пределами. Raw дал 0/96, контрольная проза — 16/16. Одно окно занимает 240 символов страницы. [Протокол, карточки и оценки](../notes/experiments/babel1_readability.md)
У нового прототипа с двумя предсказаниями проверены обе стороны адресации на всех 65 536 двузначных страницах и граничных номерах полной длины. На первых `2^64` адресах первые 4088 знаков совпадают с текстом генератора. Связность зависит от выбора генератора.
Qwen3:1.7b Q4_K_M подключена к двум предсказаниям. На 44-м и 88-м совпали полные страницы 0 и 1 и их обратные адреса после перезапуска. На 88-м пересчитана независимо заданная страница со всеми 256 знаками. Русский пример повторяет начало во второй половине. [Проверка, команды и тексты](../notes/experiments/generative_coupling.md)
Шесть LLM написали 24 рассказа по заданным сюжетам. Полных причинных цепочек — 0/24. Среди пакетов до 3 ГБ по дополнительным критериям первой стала Gemma 3 1B. [Тексты и слепые оценки](../notes/experiments/small_models.md)
Оригинал первой страницы «Белых ночей» и её перемешанный вариант вернулись по адресам на глубине 45,36% диапазона. Номер оригинала чуть меньше. Для проверки на разных произведениях нужны новые пары.
На восьми новых ранних адресах Qwen3 две пары ИИ-читателей нашли читаемый абзац на 5/8 и 8/8 страниц, на восьми далёких у обеих 0/8. В первых восьми повторы между половинами достигали 58–834 знаков. [Полностраничный пилот](../notes/experiments/qwen3_address_pilot.md)
Начата слепая проверка улучшенного продолжения на новых номерах 32–43. Сравниваем прежнюю и новую Qwen при совпадающем начале, paragraph 0.85/64 и word 0.55. Следующий шаг — заморозить код на разработческих зернах и оценить полные страницы. [Заранее заданные правила](../notes/experiments/continuation_study/protocol.json)
