# Состояние Babel — читать первым

## Продуктовая цель

Одна настоящая библиотека всех 4096-символьных страниц: каждая имеет точный
адрес, а ранний порядок должен в будущем давать разные связные человеческие
тексты без подмены маршрутами или процедурной литературой.

## Что доказано и работает

- Raw библиотека: `Σ^4096 ↔ 0…2^32768−1`, text/address/open/back/forward.
- Babel-1: обратимая 4096-символьная биекция через shell + контекстную
  перестановку; API round-trip и production round-trip проверены.
- Канонический production: `https://all.bezrabotnyi.com/library.html`.
- `https://babel.bezrabotnyi.com/*` делает 308 на canonical `all`.
- TLS для обоих имён работает; Babel-1 reader на production открывается.

## Что НЕ готово / нельзя обещать

- Babel-1 `rank ± 1` не является смысловым или читаемым соседством.
- Markov-5 даёт буквенный ранний слой, но не связную русскую речь.
- «Читательский маршрут» в UI — только подписанные контрольные цитаты public
  domain; он не доказывает качество нумерации и не должен подменять её.
- Глобальный semantic rank/unrank по энергии исходной модели не готов.

## Главное направление, которое нельзя забывать

`experiments/hierarchical_enumerator_v1.py` теперь даёт конечный честный MVP:
31 абзац → 961 двухабзацная страница → exact raw-space transposition fallback.
Есть exact count/rank/unrank для каталога и полного `256^4096` пространства;
глобальной сортировкой смысла это не является и так в продукте не называется.

## Проверенные студенты

- Fixed-seed `eval_harness_v2`: все 24 конфигурации завершены; формально лучший
  `word, temp=0.55` (106.4101), но его пример — смешанные обрывки, не проза.
- FSM — шум; sentence/paragraph задают форму, но не связность; лишь 142 из 800
  paragraph-shape содержат несколько предложений; A* frontier — sampler.
- Markov-5 прошёл exact 4096 round-trip на 9 адресах, но его начало — смесь
  букв без слов. Это baseline биекции, не кандидат для читательского начала.

## Ближайший честный canary
Пройдено на `all.bezrabotnyi.com`: reader/API открывают №0 и №1 как читаемые,
№961 как raw fallback; public round-trip проходит. `babel` делает 308 на `all`.
Следующий шаг — расширять catalogue или обучать новый смысловой student.
