# Генераторы в браузере

С главной откройте «Полный explorer» → «Генераторы». Страница загружает таблицы моделей и строит текст в браузере. [Открыть генераторы](https://all.bezrabotnyi.com/generate.html) · [Карта сайта](../README.md#карта-сайта)

## Шесть режимов генератора

При открытии уже сгенерирован текст в режиме **cluster student v1**. По умолчанию Seed — строка `42`, Length — `512`. Выберите Mode, при желании измените Seed и Length (32–4096) и нажмите **Generate**. При тех же таблицах, режиме, seed и длине результат воспроизводится. 20 ноября 2026 года во всех шести режимах повтор с `42` дал прежний текст, замена на `43` — другой.

Числа в таблице получены кнопкой **Score generated** при Seed `42` и Length `512`. Запрошенная длина управляет генерацией. Поле `length` в отчёте измеряет длину получившегося нормализованного текста в единицах UTF-16. Например, для legacy class-FSM 512 сгенерированных знаков заняли 519 таких единиц.

| Mode на экране | Как получается текст | `length` | `energy` |
| --- | --- | ---: | ---: |
| cluster student v1 | Хеш контекста задаёт кластеры. Генератор переходит между ними и выбирает токен внутри кластера. | 510 | 192 340 |
| cluster student v2 (k-means) | Тот же алгоритм выбора использует кластеры, полученные методом k-means из векторов контекста. | 512 | 195 026 |
| paragraph/hierarchical student | Форма абзаца задаёт последовательность шаблонов предложений. Каждый шаблон заполняется словами. | 512 | 231 099 |
| sentence/word student | Шаблон предложения задаёт типы токенов. Слова подбираются с учётом переходов. | 512 | 220 766 |
| word student | Переходы между словами определяют выбор следующего токена. | 493 | 204 702 |
| legacy class-FSM | Конечный автомат выбирает следующий класс символов, затем символ этого класса. | 519 | 367 895 |

### Что считает Score

Отредактируйте текст под кнопками и нажмите **Score generated**. У всех шести режимов один оценщик. Он приводит буквы к нижнему регистру, нормализует знаки и заменяет неизвестные символы пробелами. К стоимости переходов между классами и выбора символов он добавляет штрафы за длинные повторы и серии пробелов. После новой генерации нажмите Score ещё раз, чтобы обновить отчёт.

В ответе видны `normalized` (текст после нормализации), `unknown` (число замен неизвестных символов), `length`, сумма `energy` и `energyPerSymbol = energy / max(1, length)`. Проверочный ввод `МИР雪` дал «мир» с пробелом в конце, одну замену, длину 4, энергию 1556 и 389 на единицу длины во всех режимах. ## Поиск по библиотеке Qwen

Читалка открывает № 32 в издании Qwen3.5 и № 41 в издании Qwen3. На широком экране текст набран в две колонки, на телефоне — в одну. Кнопки «Назад по тексту» и «Дальше по тексту» позволяют дочитать все 4096 знаков, сохраняя текущий номер. «Предыдущая» и «Следующая» возле заголовка открывают соседние номера в том же издании. Ссылку на открытый номер можно скопировать из адресной строки. В разделе «Найти номер по тексту» можно ввести свою фразу, загрузить файл UTF-8 или вставить открытую страницу. Меню «⋯» возле заголовка позволяет скопировать или скачать все 4096 знаков открытой страницы. [Страница № 32](https://babel.bezrabotnyi.com/search.html?mode=qwen35_reference_v1#rank=32)

Каждое издание принимает страницы из 4096 знаков своего алфавита. Браузер показывает знаки вне алфавита и их позиции в исходном тексте. Например, узкий неразрывный пробел U+202F из набранного текста заменяется обычным пробелом. Каждый такой знак занимает одну позицию, даже если это эмодзи. Разрешённые буквы, эмодзи и переводы строк LF сохраняются. В последовательности CRLF заменяется только CR. Короткий текст дополняется пробелами справа, более длинный сайт просит сократить. Поиск, копирование и скачивание используют одну и ту же подготовленную страницу. [Открыть Qwen3](https://babel.bezrabotnyi.com/search.html?mode=qwen_reference_v1) · [Открыть Qwen3.5](https://babel.bezrabotnyi.com/search.html?mode=qwen35_reference_v1)

После успешного поиска или открытия сайт записывает полный текст и номер в SQLite. Одной записи достаточно для поиска в обе стороны. Кеш сохраняется при перезапуске сайта, для каждого издания действует своя нумерация. По умолчанию файл расположен в `~/.local/state/babel/qwen-pages.sqlite3`. Если задан `XDG_STATE_HOME`, каталог состояния берётся оттуда. Полный путь можно задать через `BABEL_PAGE_CACHE_PATH`. В ответе веб-API `cached: true` означает, что результат получен с диска. Чтобы отправить исходный текст напрямую в `/api/rank` с теми же заменами, передайте `"replace_unsupported": true`. По умолчанию прямой API проверяет алфавит строго.

## Локальный запуск

Чтобы открыть только генераторы, выполните команду из корня репозитория и перейдите на [локальную страницу генераторов](http://127.0.0.1:8088/generate.html).

```bash
python3 -m http.server 8088 --bind 127.0.0.1 --directory site
```

Для главной, каталога, Babel-1 и серверных режимов поиска запустите Flask. Он обслуживает сайт и API на одном порту. Для вычисления новых страниц запустите контейнер выбранного издания. Qwen3 по умолчанию слушает на `127.0.0.1:18862`, Qwen3.5 — на `127.0.0.1:18872`. [Запуск сайта с API](../README.md#локальный-запуск) · [Контейнер Qwen3](../deploy/qwen-reference/README.md) · [Контейнер Qwen3.5](../deploy/qwen35-reference/README.md)
