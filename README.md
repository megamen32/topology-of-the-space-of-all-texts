# Библиотека Вавилона

В библиотеке можно найти адрес текста и по адресу открыть страницу. Попробуйте № 0 и № 1 в разделе «Читаемое начало», затем № 961 — первую страницу за границей подборки. [Открыть библиотеку](https://all.bezrabotnyi.com/library.html)

## Как текст получает адрес

На каждой из 4096 позиций можно поставить любой из 256 знаков алфавита. Две позиции дают 256 × 256 вариантов, вся страница — `256^4096 = 2^32768`. Номера идут от нуля до `2^32768 − 1`.

В обычном режиме (**raw**) каждому знаку соответствует цифра от 0 до 255. Записанные подряд, эти цифры дают адрес страницы в системе с основанием 256. Операция `rank` вычисляет адрес, `unrank` восстанавливает страницу. Например, поиск «Мир» вернёт адрес слова «мир», дополненного справа пробелами до 4096 знаков. Адрес можно записать десятичным числом или в формате `page64`.

## Откуда берётся читаемое начало

В каталоге 31 готовый русский абзац. Из них составляют пары с учётом порядка и повторами. Получается **31 × 31 = 961 страница** с номерами от 0 до 960. Каждая пара меняется местами со страницей, которая прежде занимала её новый номер. С № 961 идут обычные страницы исходного алфавита с учётом этих обменов. Поэтому любую страницу можно открыть ровно по одному адресу в этом режиме.

Сохраняйте номер вместе с названием режима. В raw номер 0 открывает 4096 пробелов, в каталоге — два абзаца. Различаются и алфавиты. У обычного поиска алфавит нормализован, а каталог и модель Babel-1 используют исходный алфавит с 54 заглавными буквами. Читательский маршрут отдельно открывает подписанные цитаты.

## Что измеряет энергия Babel-1

Babel-1 читает страницу слева направо. По уже прочитанному тексту модель упорядочивает все 256 вариантов следующего знака. Места с 1-го по 16-е стоят 0, с 17-го по 256-е — 1. **Энергия `s` — число позиций, где знак оказался за пределами первых 16.** Она может быть от 0 до 4096.

Страницы с одной энергией образуют оболочку. Её размер — `C(4096, s) × 16^(4096 − s) × 240^s`. Первый множитель считает способы выбрать `s` позиций. На каждой выбранной позиции есть 240 вариантов, на каждой оставшейся — 16. Даже при нулевой энергии возможны `16^4096` разных страниц.

Адрес — число страниц в оболочках меньшей энергии плюс номер внутри своей, считая с нуля. Внутри оболочки номера перемешаны по фиксированному правилу, поэтому соседние страницы могут сильно различаться. При открытии адреса модель строит те же списки слева направо и по месту каждого знака восстанавливает текст.

## Что показала слепая проверка

Оценку «да» ставили за понятное высказывание хотя бы из пяти связанных слов. В каждой из трёх групп Babel-1 её получили **0 из 32** фрагментов. Проверяли адреса 0–31, случайные адреса в остальной части нулевой оболочки и случайные адреса за её пределами. В raw на тех же адресах результат — **0 из 96**, в «Белых ночах» Достоевского — **16 из 16**. В ранних фрагментах Babel-1 буквы составили 94,3% знаков, в глубоких — 47,3%.

С каждой выбранной страницы Babel-1 и raw брали один фрагмент длиной 240 знаков из 4096. Два запуска одной ИИ-модели провели изолированно, скрыв адреса. Оценки совпали на всех 208 карточках. Независимая оценка людьми и частота связных текстов во всей библиотеке остаются открытыми вопросами. [Протокол слепой проверки](notes/experiments/babel1_readability.md)

## Локальный запуск

Запуск из чистой копии проверен на Python 3.10. В изолированном окружении из `requirements.txt` установились Flask 3.1.3 и `regex`. Исходный алфавит, индекс Markov-5 и сжатые без потерь строки таблицы входят в репозиторий. Выполните команды в Bash из его корня.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiments/test_markov5_artifacts.py
python experiments/test_hierarchical_enumerator_v1.py
python experiments/test_babel_1_api.py
python experiments/backend_app.py
```

После запуска откройте каталог № 0 или введите свою фразу в поле «Найти обычный адрес». [Локальная читалка](http://127.0.0.1:8090/library.html)
