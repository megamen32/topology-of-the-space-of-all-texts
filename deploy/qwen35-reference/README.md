# Издание Babel Qwen3.5 4B

Издание `babel-qwen35-ref-v1` использует модель Qwen3.5 4B Q4_K_M. Адреса принадлежат этому изданию и вычисляются отдельно от издания Qwen3 1.7B. Каждая страница содержит 4096 знаков алфавита Babel. Короткий текст при поиске дополняется пробелами справа.

Контейнер закрепляет байты модели, CPU-библиотеку Haswell, llama.cpp и правила двух предсказаний. Он применяет жадный выбор токена с температурой 0. Первоначальное сравнение модели с кандидатами использовало выбор с температурой 0,49 и другие начала. Качество текста контейнерного издания требуется оценивать отдельно.

Для сборки из корня репозитория установите Docker Buildx и запустите

```sh
./deploy/qwen35-reference/build.sh
docker run -d --name babel-qwen35-reference-v1 --read-only \
  -p 127.0.0.1:18872:8081 babel-qwen35-reference:v1
curl -fsS --retry 60 --retry-all-errors --retry-delay 1 http://127.0.0.1:18872/health
```

Скрипт проверяет SHA-256 весов, всех файлов вычислителя и кода. Для использования уже загруженной модели задайте `BABEL_QWEN35_GGUF`, для установленного Ollama 0.32.1 — `BABEL_OLLAMA_LIB`. Служба выдаёт свой идентификатор издания на `/health`, `/rank` и `/unrank`.

Веб-сервер обращается к `http://127.0.0.1:18872` по умолчанию. Путь можно задать через `BABEL_QWEN35_ENDPOINT`. На странице Search выберите «Qwen3.5 4B · 4096 знаков» или откройте ссылку с `?mode=qwen35_reference_v1`.

Пример открытия страницы через API контейнера

```sh
curl -fsS http://127.0.0.1:18872/unrank \
  -H 'Content-Type: application/json' -d '{"address":"0x20"}'
```

Расчёт полной страницы на CPU может занять несколько минут. Контейнер обслуживает запросы последовательно и сохраняет в памяти только успешно вычисленные предсказания.
